      About this project

      The heart-disease notebook was converted into a runnable Python script (train.py) and wrapped in this Flask web application. Five binary classifiers (a neural network plus logistic regression, random forest, Gaussian naive Bayes and K-NN) and one 5-class severity network are trained on the UCI Cleveland dataset. All models are exported to a single JSON file and evaluated in pure Python, so the site deploys to Vercel without TensorFlow or scikit-learn.

      Disclaimer: this is an educational machine-learning demo built on a small public dataset. It is not a medical device and must not be used for real clinical decisions.

      Built with Keras & scikit-learn · Served with Flask · Deployed on Vercel
